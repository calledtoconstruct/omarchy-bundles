Activities you can add and remove.

8 bundles group the packages, plugins, skills, and config for one kind of work. Copy the install command, then read what that bundle changes.

This catalog is not part of stock Omarchy. The omarchy bundle command is proposed in pull request 15603. A git URL installs only a repository whose root contains bundle.json, and that command warns the source is unreviewed. Each bundle here lives in a subfolder, so the command clones this catalog and adds that folder.
