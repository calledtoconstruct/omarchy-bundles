# Web Developer

GitHub CLI, Docker Buildx, mkcert, and DBeaver are installed. Docker, mise, Neovim, and Chromium were already part of Omarchy.

A project lives under `~/Work`. Create one with `omarchy bundle project new webdev <name>`. The create script can run `mise use` and can make a local certificate with mkcert, both only after you confirm. DBeaver is the desktop client for the Postgres service that script writes.

If you enabled the plugins, the bar can show GitHub reviews, listening ports, Docker containers, and a stable `<name>.localhost` name for a dev server.

An editorconfig was copied to `~/.config/omarchy-bundles/webdev/editorconfig`.
