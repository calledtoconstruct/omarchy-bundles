# Creator

EasyEffects, Audacity, the v4l2loopback tools, and the AUR package obs-pipewire-audio-capture are installed. OBS Studio, Kdenlive, and GPU Screen Recorder were already part of Omarchy.

obs-pipewire-audio-capture records one application's audio inside OBS. EasyEffects processes the microphone. Audacity edits a voice track outside the video timeline. v4l2loopback provides a virtual camera.

A project lives under `~/Videos/Projects`. Create one with `omarchy bundle project new creator <name>`. The folder has script, raw, assets, edit, and export.

If you enabled the plugins, the bar can show a movable camera window, a webcam preview, on-screen keystrokes, audio device controls, and a virtual microphone for OBS, Zoom, and Meet.
