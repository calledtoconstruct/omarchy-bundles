# Study

Anki, Typst, Pandoc, Zathura, Harper, and Zotero are installed. Zotero is the AUR package `zotero-bin`.

A course lives at `~/School/<term>/<course>/`. Create one with `omarchy bundle project new study <course>`. The folder gets a syllabus, an assignment, and a bibliography. The create script does not write Anki's collection or open an Obsidian vault on its own.

Zathura reads PDFs. Typst is for assignments. Pandoc converts a Word or Markdown draft. Harper checks grammar and spelling.

If you enabled the plugins, the bar can show a review count, focus windows, a timer, and today's Obsidian daily note. The review widget keeps its own deck. It does not read Anki's collection. The daily-note widget needs the vault path in its settings.
